# Инструкция: парсинг статей словаря 1 (карачаево-балкарско-русский переводной словарь)

Вход: JSON-массив статей `[{seqid, word, hom, decl, text}]`. Поле `text` — статья с уже раскрытой тильдой (заглавное слово подставлено) и снятой типографской разметкой. Текст чистый (не OCR), исправлять ничего не нужно — только РАЗДЕЛИТЬ на поля.

Для каждой статьи верни объект:

- `seqid` — скопируй из входа (число).
- `word` — скопируй из входа без изменений.
- `tags` — пометы, относящиеся ко ВСЕЙ статье, стоящие в её начале: грамматические ("межд.", "союз", "частица"), стилистические ("разг.", "уст.", "фольк.", "этн.", "ист."), отраслевые ("бот.", "мед.", "мат.", "лингв.", "текст."), диалектные ("карач.", "балк."), религиозные ("мус."), и реляционные ("понуд. к X", "отвлеч. к X", "и. д. к X", "страд. к X", "взаимн. к X", "прич. от X", "усил. к X" — вместе с их словом-целью X). Пометы отдельных значений (после цифр 1) 2)) сюда НЕ входят. Если помет нет — пустая строка.
- `def1` — русский перевод/определение: все значения с их нумерацией (1) … 2) … или 1. … 2. …) и пометами значений, разделитель "||" сохраняется. НЕ включай примеры-словосочетания и предложения с их переводами. Для отсылочных статей ("см. X", "то же, что X") — сама отсылка ("см. X").
- `misc1` — ВСЁ остальное в исходном порядке: карачаево-балкарские примеры с русскими переводами, пословицы (посл.), поговорки (погов.), загадки с отгадками, фразеология, управление ("кого-что", "кому"), формы склонения, прочие уточнения в скобках, "букв." — буквальные переводы.
- `flags` — массив строк из набора: `"ref_only"` (статья — только отсылка), `"split_unclear"` (не уверен, где кончается перевод и начинаются примеры), `"needs_review"` (что-то странное в статье). Обычно пустой `[]`.

## Жёсткие правила

1. НИЧЕГО не терять: каждый содержательный фрагмент `text` должен попасть ровно в одно из полей tags/def1/misc1. Не пересказывать, не сокращать, не переводить.
2. Разделитель значений и порядок текста сохранять как есть.
3. `def1` может быть пустым только у отсылочных статей без перевода.
4. Скобочная помета склонения уже вынесена в `decl` — в поля её не дублируй, она придёт в итог отдельно.

## Примеры

Вход: `{"seqid": 25090, "word": "таукелсиз", "text": "несмелый, нерешительный; безвольный || несмело, нерешительно, неуверенно, безвольно; таукелсиз адам нерешительный человек, неуверенный [в себе] человек; безвольный человек"}`

Выход: `{"seqid": 25090, "word": "таукелсиз", "tags": "", "def1": "несмелый, нерешительный; безвольный || несмело, нерешительно, неуверенно, безвольно", "misc1": "таукелсиз адам нерешительный человек, неуверенный [в себе] человек; безвольный человек", "flags": []}`

Вход: `{"seqid": 35, "word": "абрек", "text": "1) ист. абрек, разбойник 2) ист. изгой 3) обиженный человек; абрек иерге обидеть кого, нанести обиду кому; абрек кетерге обидеться на кого-что"}`

Выход: `{"seqid": 35, "word": "абрек", "tags": "", "def1": "1) ист. абрек, разбойник 2) ист. изгой 3) обиженный человек", "misc1": "абрек иерге обидеть кого, нанести обиду кому; абрек кетерге обидеться на кого-что", "flags": []}`

Вход: `{"seqid": 54, "word": "абызыратыргъа", "text": "понуд. к абызыраргъа 1) привести кого в замешательство, ошеломить, обескуражить кого 2) привести кого в изнеможение, измучить, измотать кого-что"}`

Выход: `{"seqid": 54, "word": "абызыратыргъа", "tags": "понуд. к абызыраргъа", "def1": "1) привести кого в замешательство, ошеломить, обескуражить кого 2) привести кого в изнеможение, измучить, измотать кого-что", "misc1": "", "flags": []}`

## Формат результата

Запиши в указанный выходной файл JSON вида:
```json
{"entries": [ {"seqid": ..., "word": "...", "tags": "...", "def1": "...", "misc1": "...", "flags": []}, ... ]}
```
Количество объектов = количеству входных статей, порядок тот же. Файл в UTF-8 без BOM.
