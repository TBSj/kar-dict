# Инструкция: таксономия содержимого полей misc1/misc2 объединённого словаря

Вход: JSON `{samples: [{stratum, entry_id, word, tags, def1, def2, misc1, misc2}]}` — стратифицированная выборка статей объединённого карачаево-балкарского словаря. misc1 — «всё кроме перевода» из переводного словаря (КъМ-русский, Гочияева/Суюнчев); misc2 — «всё кроме русской части определения» из толкового словаря (ТСКБЯ).

Задача — исследовательская: внимательно изучи, КАКИЕ ТИПЫ содержимого встречаются в misc-полях, как они выглядят в разных статьях и что означают. Составь:

1. **Инвентарь типов содержимого** для misc1 и misc2 отдельно. Ожидаемые кандидаты (проверь и дополни своими наблюдениями):
   - примеры-словосочетания с переводом; примеры-предложения с переводом;
   - пословицы (посл.), поговорки (погов.), загадки с отгадками, фольклорные формулы, благопожелания;
   - цитаты из литературы с указанием автора/произведения/страницы (ТСКБЯ: «Хубийланы О., Аманат, I, 76», «Шуёхлукъ», № 39);
   - карачаево-балкарское толкование (в misc2, после «/» оригинала);
   - фразеологизмы (◊) и составные термины (□);
   - отсылки («къ.» в ТСКБЯ, «см.», «то же, что» в переводном);
   - грамматическое управление (кого-что, кому...); формы склонения; диалектные пометы (карач./балк.) на уровне значений; «букв.» — буквальный перевод; варианты написания.
2. **Частотную оценку**: какие типы часты, какие редки (по выборке).
3. **Предложение типизированных подполей**: как логично разложить misc на поля (например misc2_kb_def, misc2_examples, misc2_citations, misc_phras, misc_xref, misc1_examples, misc1_folklore...). Для каждого подполя: чёткий критерий выделения и НАДЁЖНЫЙ формальный признак (регулярное выражение/маркер), если он существует; если надёжного признака нет — честно скажи, что выделение потребует LLM или ручной работы.
4. **Правила-регэкспы**, которые можно применить детерминированно (протестируй мысленно на образцах выборки; приведи для каждого правила 2-3 сработавших примера из выборки и известные ложные срабатывания).

## Формат результата

Запиши TWO файла:
1. Отчёт на русском (Markdown) — в файл, путь которого указан в задании (taxonomy report). Структура: Инвентарь misc1 / Инвентарь misc2 / Частоты / Предлагаемые подполя / Регэксп-правила / Риски.
2. Машинные правила JSON — второй указанный путь: `{"rules": [{"field": "misc2_citations", "source": "misc2", "regex": "...", "mode": "extract_all|split_after_marker", "comment": "..."}]}`.
