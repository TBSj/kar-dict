# Инструкция: классификация слов на Ж-/ДЖ- без пары во втором словаре

Вход: JSON-массив `[{dict, word, def}]`: слова на дж- (из карачаевского переводного словаря, dict=1) или на ж- (из балкарского толкового словаря, dict=2), для которых НЕ нашлось соответствия в другом словаре. `def` — определение/перевод для контекста.

Для объединённого словаря важно отделить:
- `loanword` — заимствования из русского/интернациональные (журнал, жираф, жюри, джунгли, джентльмен, джаз…): их написание НЕ трогаем.
- `native` — исконные карачаево-балкарские (тюркские) слова и старые ассимилированные заимствования из арабского/персидского, где ж-/дж- — диалектный вариант одного звука (джаш/жаш «парень», джол/жол «дорога»): такие слова при отсутствии пары уходят на ручную проверку лингвисту.
- `unsure` — не удаётся уверенно решить.

Учитывай: русские заимствования обычно и выглядят по-русски (корень узнаваем), исконные — типичная тюркская фонотактика (гармония гласных, къ/гъ, аффиксы -лыкъ/-ныкъ/-чы и т. п.).

## Формат результата

Запиши в указанный выходной файл JSON:
```json
{"items": [{"dict": 1, "word": "джунгли", "kind": "loanword"}, …]}
```
UTF-8 без BOM.
