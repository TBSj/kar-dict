# Инструкция: какой знак напечатан перед фрагментом статьи ТСКБЯ (проверка по изображению страницы)

Толковый словарь КБ языка (ТСКБЯ) использует в статьях знаки (легенды т. 1 PDF-с. 30, т. 2–3 PDF-с. 10; в разных томах они разные, проверено по изображениям 2026-11-05):
- **т. 1:** полый квадрат ❑ — составные слова (и начало цитат), залитый треугольник ▲/▼ — фразеологизмы;
- **т. 2–3:** залитый квадрат ■ — составные слова, залитый ромб ♦ — фразеологизмы, полый ▭/❑ — начало цитат;
- во всех томах: **полый кружок ○** — начало цитат после пословицы «(Нарт сёз.)»;
- **никакого знака** — следующая единица внутри уже открытой зоны: полужирное сочетание идёт сразу после подписи предыдущей цитаты (например «…поэмала, 81. **Жан-жа…**»).

Вход: JSON-массив `[{id, word, vol, page, raw_snip, block}]`. Для всего файла сразу построй картинки командой:
```
"D:/Projects/My_projects/Python/Py_projects/kar-dict/.venv/Scripts/python.exe" -I -X utf8 D:/Projects/My_projects/Python/Py_projects/kar-dict/pipeline/survey_tools/crop_batch.py <входной_файл> <папка_для_картинок>
```
Она печатает для каждого id путь к PNG или NOT_FOUND. На картинке — строка колонки с нужным фрагментом и строка над ней; первое слово фрагмента обведено красной рамкой. Посмотри (инструмент чтения файлов) на символ, стоящий НЕПОСРЕДСТВЕННО перед обведённым словом (он может быть в конце предыдущей строки, если обведённое слово начинает строку), и определи:

- `filled` — залитый знак (квадрат ■, ромб ♦ или треугольник ▲) — укажи форму в поле `shape`: `square` | `diamond` | `triangle`;
- `hollow` — полый квадрат ❑/□;
- `circle` — кружок ○;
- `none` — знака нет (перед словом точка/номер страницы цитаты/пробел);
- `unclear` — не видно, не найдено (NOT_FOUND) или рамка стоит не на том месте (текст в рамке не совпадает с началом `block`).

## Формат результата

Запиши в указанный выходной файл JSON:
```json
{"items": [{"id": "e_00265@4100", "glyph": "none", "shape": "", "note": ""}, …]}
```
Каждому входному `id` — ровно одна запись, в том же порядке. В `note` — что видно, если ответ не очевиден. UTF-8 без BOM.
