# Инструкция: слияние словарных статей и выравнивание омонимов

Вход: JSON-массив групп. Каждая группа — одно заглавное слово с материалом из двух словарей:
- `d1` — статьи карачаево-балкарско-русского ПЕРЕВОДНОГО словаря: `{seqid, d1_word, word_base, hom_src, tags, decl, def1, misc1}`. В группе могут быть статьи РАЗНЫХ слов d1 (например существительное «тал» и глагол «талыргъа»), сведённые к одному заглавному слову толкового словаря — это нормально, распределяй каждую по подходящему омониму d2.
- `d2` — статьи ТОЛКОВОГО словаря (ТСКБЯ): `{source_ids, hom, tags, def2, misc2}`.
- `word_base_map` — какое итоговое написание (`word_base`) использовать: для статьи результата, содержащей материал d1, бери `word_base` этой d1-статьи; для статьи только из d2 бери `word_base_map["_d2only"]`.

В группе больше одной статьи хотя бы с одной стороны — это омонимы/разделённые статьи. Твоя задача: собрать ЛОГИЧЕСКИЕ статьи объединённого словаря, семантически сопоставив стороны.

## Правила

1. Опорная структура — омонимы словаря d2 (толкового): каждый его омоним (hom I, II, 1, 2…) даёт отдельную статью результата. Статьи d1 распределяй по ним семантически.
2. Если одна статья d1 покрывает НЕСКОЛЬКО омонимов d2 (например, в d1 прилагательное и наречие слиты через "||"), РАЗДЕЛИ её def1/misc1 по смыслу: часть до "||" — к омониму-прилагательному, после "||" — к наречию, и т. п. Если разделить уверенно нельзя — продублируй def1 целиком в обе статьи и поставь флаг `"dup_def1"`.
3. Если статья d1 не соответствует ни одному омониму d2 — она становится отдельной статьёй результата с dict_id="1". Аналогично для d2 без пары: dict_id="2".
4. `tags`: возьми пометы d2; если у статьи d1 есть содержательные пометы, которых нет в d2 (напр. "карач.", "понуд. к X"), добавь через "; ".
5. Ничего не терять и не выдумывать: каждый def1/misc1/def2/misc2 исходных статей должен попасть (целиком или осмысленной частью при разделении) хотя бы в одну статью результата.
6. `hom_rank`: порядковый номер омонима по нумерации d2 (I→1, II→2, 1→1, 2→2); для статей без пары d2 — 90+порядок в d1.
7. `dict_id`: "both" если в статье есть материал обоих словарей, иначе "1" или "2".

## Формат результата

Запиши в указанный выходной файл JSON:
```json
{"groups": [
  {"match_id": "m_00123", "entries": [
     {"word_base": "таукелсиз", "dict_id": "both", "tags": "сыф.",
      "def1": "несмелый, нерешительный; безвольный", "def2": "Нерешительный, несмелый; безвольный",
      "misc1": "…", "misc2": "…",
      "src1": [25090], "src2": ["d2_18xxx"],
      "word1_orig": "таукелсиз", "word2_orig": "таукелсиз", "decl": "",
      "hom_rank": 1, "flags": []},
     {"word_base": "таукелсиз", "dict_id": "both", "tags": "хал. сёзл.",
      "def1": "несмело, нерешительно, неуверенно, безвольно", "def2": "Нерешительно, несмело, неуверенно, безвольно",
      "misc1": "…", "misc2": "…", "src1": [25090], "src2": ["d2_18yyy"],
      "word1_orig": "таукелсиз", "word2_orig": "таукелсиз", "decl": "", "hom_rank": 2, "flags": ["split_def1"]}
  ]}
]}
```
Возможные флаги: `"split_def1"` (def1 разделён), `"dup_def1"` (продублирован из-за неуверенности), `"no_d2_pair"`, `"no_d1_pair"`, `"needs_review"`. Файл в UTF-8 без BOM.
