# Инструкция: перевод карачаево-балкарских глаголов из инфинитива в повелительное наклонение ед. ч.

Вход: JSON-массив `[{word, candidates, def1}]` — глаголы карачаево-балкарского языка в инфинитиве (-ргъа/-рге), встречающиеся только в переводном словаре. `candidates` — механически построенные варианты основы, `def1` — русский перевод (для контекста).

Задача: для каждого глагола дай форму повелительного наклонения единственного числа (= чистая основа глагола, как заглавные слова в толковом словаре ТСКБЯ).

## Морфология

Инфинитив = основа + (соединительный гласный) + р + гъа/ге:
- основа на гласный: `окъу-` → `окъургъа` (окъу+р+гъа); повелит. = **окъу**; `абызыра-` → `абызыраргъа`; повелит. = **абызыра**; `тиле-` → `тилерге`; повелит. = **тиле**.
- основа на согласный: соединительный гласный ы/и/у/ю по сингармонизму: `бар-` → `барыргъа` (бар+ыр+гъа); повелит. = **бар**; `бер-` → `берирге`; повелит. = **бер**; `тур-` → `турургъа`; повелит. = **тур**.
- отглагольные основы на -ла/-ле, -лан/-лен, -лаш/-леш, -дыр/-дир, -тыр/-тир, -ыл/-ил, -ын/-ин, -ыш/-иш сохраняются целиком: `табанларгъа` → **табанла**, `жабагъыланыргъа` → **жабагъылан**, `таблашдырыргъа` → **таблашдыр**.
- конечные звонкие основы оглушаются в конце слова: `тагъаргъа` (основа тагъ-) → повелит. **такъ**; `чабаргъа` → **чаб/чап** — здесь сохраняй орфографию исходного словаря: конечную **б** оставляй как б (карачаевская норма), гъ→къ и г→к применяй всегда.

Главный вопрос в неоднозначных случаях: является ли гласный перед -р- частью основы или соединительным? Реши по морфологии тюркских основ и знанию карачаево-балкарского. Если реально не уверен — выбери наиболее вероятный вариант и поставь `"confidence": "low"`.

## Формат результата

Запиши в указанный выходной файл JSON:
```json
{"items": [{"word": "табанларгъа", "imperative": "табанла", "confidence": "high"}, …]}
```
UTF-8 без BOM.
