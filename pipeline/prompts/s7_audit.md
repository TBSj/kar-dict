# Инструкция: финальный аудит статей объединённого словаря против первоисточников

Вход: JSON `{tasks: [{entry, d1_raw, d2_pages}]}`:
- `entry` — итоговая статья объединённого словаря: {word, dict_id, tags, def1, def2, misc1, misc2, lextag, word1_orig, word2_orig, flags…};
- `d1_raw` — исходные статьи переводного словаря (сырой текст с разметкой: @…# — карачаево-балкарский текст, $…% — курсивные пометы, ~ — заглавное слово, || — параллельный перевод);
- `d2_pages` — пути к PNG-страницам толкового словаря (ТСКБЯ); НАЙДИ на изображении статью word2_orig и сверь с ней.

Проверь КАЖДУЮ статью по пунктам:
1. **word**: правильно ли образовано (строчные; латинская j на месте дж/ж-соответствия; латинская b на месте конечного б/п-соответствия; глагол в повелительном наклонении ед.ч.; цифра омонима корректна)?
2. **def1**: точно ли передан русский перевод из d1_raw (без потерь и добавлений)? Примеры не должны попасть в def1.
3. **def2**: только русская часть определения из ТСКБЯ (сверь с изображением страницы)? КБ-толкование не должно быть в def2.
4. **misc1/misc2**: всё остальное содержимое статей сохранено? OCR-исправления корректны (сравни misc2 с изображением: фамилии авторов, цитаты)?
5. **tags**: соответствуют пометам источников?
6. **lextag**: разумна ли семантическая категория?
7. Для dict_id="both": действительно ли d1 и d2 описывают ОДНО слово/значение (не ложное слияние)?

Оценка каждой статьи: `"ok"` | `"minor"` (мелкие огрехи, перечисли) | `"major"` (потеря содержания, неверное слияние, неверная форма слова — обязательно объясни).

## Формат результата

Запиши в указанный выходной файл JSON:
```json
{"audits": [{"word": "…", "entry_id": "…", "verdict": "ok|minor|major",
             "issues": [{"field": "def2", "problem": "…", "severity": "minor|major"}]}]}
```
Будь строг: это словарь для носителей языка и изучающих, ошибки недопустимы. UTF-8 без BOM.
