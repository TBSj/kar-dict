Статус реализации — 2026-08-07, первый проход пунктов 1–3 сделан

## 1. Типизация помет (фасеты) — СДЕЛАНО (первый проход)

Поля `pos` / `dialect` / `style` / `domain` / `gram_note` добавлены в
07_final.jsonl и final.csv/xlsx (27 855 назначений). Нераспознанный хвост —
в `tags_other` и `checkpoints/qa/s8_unmapped_tags.json` (~900 редких токенов,
ждут доразметки). Исходное поле `tags` не тронуто.

Разбить поле `tags` на независимые фасеты, чтобы фильтровать по каждому отдельно:

- часть речи (ат., эт., сыф., хал. сёзл., кес., межд., сан., алм. …)
- диалект (карач., балк., къарач. …)
- стилистика/регистр (сёл. тил., уст./эск., поэт., рел., шутл., пренебр. …)
- предметная область (мат., физ., бот., зоол., воен., грам. …)
- грамматические отношения (и. д., понуд., страд., взаимн., отвлеч., прич. …)

Задел: таксономия помет уже описана в `checkpoints/qa/s6_misc_taxonomy.md`;
нужен нормализованный справочник помет + прогон-классификатор.

## 2. Поле «дериват» — СДЕЛАНО (первый проход)

Поля `derived` (тип связи + сырое основание) и `derived_from` (найденный
заголовок базового слова) добавлены: 15 302 статьи-дериваты, 14 704 (96 %)
сцеплены с базовым словом. «Схлопывание» до разнокоренных — фильтр
`derived_from == пусто`.

Флаг + ссылка на базовое слово для всех статей с пометами «и. д. (к/от)»,
«отвлеч. к», «понуд.», «страд.», «взаимн.», «прич.» и т.п.
Цель: возможность «схлопнуть» словарь до разнокоренных лексем.
Задел: регекс семейного наследования в `pipeline/s5_consistency.py` (RE_REL)
уже вычисляет базовое слово — вынести в постоянное поле `derived_from`.

## 3. Поле «варианты слова» — СДЕЛАНО (первый проход)

Поля `variant_of` / `variants`: 739 связей по отсылкам «см./тж./къ.» с
фильтром похожести (метатезы, элизии, дж/ж-протеза: jамагъат↔jамауат,
jаман↔аман). Полный список — `checkpoints/review_queues/variants_detected.jsonl`
(на просмотр лингвисту: похожие ОТСЫЛОЧНЫЕ слова с разницей в 1–2 буквы могут
быть и синонимами, автоматика их не различает).

Связывать метатезы/элизии (ахча ↔ ачха) как одну лексическую единицу,
сохраняя оба написания. Источник связей — пометы «см.», «тж.» (уже
извлекаются в `misc2_xref`) + ручные вердикты лингвиста.
Единообразие написания НЕ навязывается — вариант остаётся заголовком,
связь нужна для статистики и этимологии.

## 5. Политика разбиения омонимов / многозначности

Открытая методологическая проблема — где омонимия, а где полисемия:

- «кир» (грязь) vs «кир» (войди) — очевидные омонимы, разные статьи;
- «ариу» (красивый/хороший) — очевидная полисемия, одна статья;
- промежуточные: «аууз» (рот/ущелье), «аякъ» (нога/чаша) — этимологическая
  связь есть, значения разошлись.

Решение лингвиста: строго ориентироваться на опубликованный словарь омонимов
КБ языка (снимает ответственность за произвольные решения). Блокируется п. 4 —
нужен сам словарь омонимов.
